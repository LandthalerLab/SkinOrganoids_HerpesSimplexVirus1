# Skin organoids infected with herpes simplex virus 1
Code for the publication on skin organoids infected with Herpes Simplex Virus 1. The original output folder from Xenium can be downloaded from https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE313919 . At this location, also the fully annotated and processed VoltRon containing the spatial data is included.

# Step 1: read in Xenium output and assign cell types
The original output folder from Xenium is read into R using VoltRon. Cell types are annotated following inclusion of the three uninfected skin organoids from the MCPyV experiment.
